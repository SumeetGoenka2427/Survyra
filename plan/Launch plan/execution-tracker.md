## 2. Weekly Funnel Review

At the end of each week, roll up the daily numbers:

```
Prospects → Replies → Demos → Trials → Paid
```

Compare week over week. If a stage is consistently the bottleneck (e.g. good replies but low demo conversion), that's where to adjust the script or offer — not where to add more top-of-funnel volume.

## 5. Content Calendar (30 days)

**Cadence:** 5 posts/week, 3 reels/week, daily stories.

- **Week 1:** Introduction · Website showcase · Survey showcase · Customer feedback problem · Review problem · Reel: website transformation · Reel: QR survey
- **Week 2:** How survey works · Website showcase #2 · Review funnel · Small business growth tip · Dashboard showcase · Reel: 5-star flow · Reel: customer feedback
- **Week 3:** Salon use case · Restaurant use case · Clinic use case · Website design showcase · Survey result example · Reel: review generation · Reel: dashboard
- **Week 4:** Client/project · Testimonial · Case study · Before/After · FAQ · Pricing · Reel: how it works · Reel: website + survey · **Free Demo CTA**

Daily stories (3–5/day) — rotate between: *"Building something for local businesses 👀"* (morning) / *"Customer feedback → review funnel"* (afternoon) / *"Want a demo? DM 'DEMO'"* (evening).
