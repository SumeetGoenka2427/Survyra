# Content Prompts — Logo, Posts, Stories, Reels

Copy-pasteable prompts for generating Instagram content and brand visuals (with an AI copywriting tool + Canva AI/Midjourney/DALL·E for visuals) — captions, stories, reel scripts, logo concepts, and post layout briefs. Brand values (name, tagline, colors, fonts) are already locked in and filled in below — the only `[bracketed]` fields left are genuinely per-post content (a specific hook, a real client quote, which reel this is for). Maps to the content calendar in [execution-tracker.md](../execution-tracker.md).

## 1. Caption Prompts (by post type — see content calendar)

**Intro / Who We Are post**
```
Write an Instagram caption (60-90 words) introducing Survyra to small business owners.
Core message: we help small businesses build a better online presence and understand their customers.
End with a soft CTA to check the link in bio. Plain language, no emojis except 1-2 max, no hashtag stuffing (max 5 relevant hashtags at the end).
```

**Website showcase**
```
Write a short Instagram caption (40-60 words) showcasing a business website we built.
Angle: highlight one specific before/after improvement (loading speed, mobile-friendliness, or looking more professional).
End with: "Want one like this for your business? DM 'DEMO'."
```

**Customer feedback / problem-agitation post**
```
Write an Instagram caption opening with the line "Your customers are already giving you feedback. Are you listening?"
Then in 2-3 short sentences, explain the cost of not collecting feedback (missed complaints, missed 5-star moments).
Close with a CTA to DM "DEMO" to see the survey system.
```

**Review funnel / diagram post**
```
Write a short caption (30-50 words) to accompany a visual diagram showing: Customer -> Survey -> Happy Customer -> Review.
Explain in one sentence why most businesses lose 5-star reviews (happy customers just don't think to leave one unless asked at the right moment).
CTA: DM "DEMO".
```

**Offer / pricing post**
```
Write a direct-offer Instagram caption for: "Survyra — Website + Customer Feedback + Review Growth, all in one monthly plan."
Mention the price starts at ₹3,000/month (or ₹2,000/month for the first 3 months under the Founding Client offer — see [pricing-offers.md](pricing-offers.md)). Keep it confident, not hypey. End with "DM 'DEMO' to see it in action."
```

**Testimonial / case study post** (once you have real client proof — see [phase-6-proof.md](../phase-6-proof.md))
```
Write an Instagram caption featuring this client testimonial: "[paste real quote]"
Business: [client name/category]. Result: [real number, e.g. "87 survey responses in month 1"].
Keep the client's own words front and center — don't paraphrase the quote. End with a CTA to DM "DEMO".
```

## 3. Reel Script Prompts

```
Write a 10-20 second Reel script (voiceover + on-screen text cues) for the hook: "[hook line]".
Structure: Hook (0-3s) -> Problem/Before (3-8s) -> Solution/After (8-15s) -> CTA (15-20s, "DM 'DEMO'").
Keep on-screen text under 8 words per cue. No background-music suggestion needed, just the script and shot list.
```

Use with these three hooks (from [phase-2-instagram-presence.md](../phase-2-instagram-presence.md)):
1. "Your website could be losing customers." (Before → After)
2. "This QR code can collect customer feedback in seconds." (Scan → Survey → Dashboard)
3. "What happens after a customer gives 5 stars?" (Survey → Review Request)

## 4. Logo Generation Prompts

Run these with Midjourney/DALL·E/an AI logo tool, or as a brief for Canva's AI logo maker. Generate 3-4 variations per prompt and pick the one that stays legible at small sizes (test at profile-photo size before deciding — see [branding-guide.md](branding-guide.md) → Logo Direction).

**Wordmark logo — use now (Phase 1, per [branding-guide.md](branding-guide.md) → Logo Direction)**
```
A minimalist wordmark logo reading "Survyra", clean modern geometric sans-serif typography (Poppins Bold style), flat design, solid #1E3A5F text on a transparent background, no icon or symbol, no gradients, no shadows, must stay legible when scaled down to a small circular profile photo, vector-style, professional SaaS/startup branding aesthetic.
```

**Icon + wordmark combination — hold for Phase 2 (5+ clients)**
```
A simple flat logo mark combining a minimalist upward-arrow icon (symbolizing growth) with the wordmark "Survyra" next to it, geometric sans-serif type (Poppins Bold style), two-color palette using #1E3A5F and #F2A93B, transparent background, no gradients, no 3D effects, must read clearly at 110x110px.
```

**Icon-only mark (for favicon/app icon use, once the wordmark is locked) — Phase 2**
```
A single-color minimalist icon mark of a simple upward-pointing arrow symbolizing growth, flat vector style, works inside a circle crop, #1E3A5F on transparent background, no text, no gradients, simple enough to be recognizable at 32x32px.
```

**Logo direction checklist**
- [ ] Generate the wordmark prompt first — it's the safer, faster path for Month 1 (per [branding-guide.md](branding-guide.md))
- [ ] Test every candidate at actual profile-photo size before picking
- [ ] Export a transparent-background PNG version for use on demo decks and the pricing sheet ([pricing-offers.md](pricing-offers.md))
- [ ] Don't generate the icon+wordmark or icon-only prompts until Phase 2 triggers (per [00-overview.md](../00-overview.md) → multi-tenant timing) — the wordmark alone is the Month 1 decision

## 6. Post Layout Prompts (Canva AI layout / template briefs)

Use these as the layout brief when generating a Canva Magic Design template or briefing a designer — they describe composition, not just visuals, so the caption/CTA always has a clear home.

**Quote / testimonial card**
```
Design a square (1:1) Instagram post layout: large quotation mark top-left, client testimonial text centered in bold readable type (max 25 words), client name + business category in smaller text below the quote, Survyra logo small in the bottom-right corner, background solid #F7F5F0 with a #F2A93B accent shape, generous padding so text never touches the edges.
```

**Before/After split**
```
Design a square (1:1) split-screen layout: left half labeled "BEFORE" showing an old/plain website screenshot placeholder, right half labeled "AFTER" showing a modern website screenshot placeholder, a bold vertical divider in #F2A93B, headline space reserved at the top ("Your website could be losing customers"), CTA bar reserved at the bottom ("DM 'DEMO'").
```

**Stat / result callout**
```
Design a square (1:1) layout with one large bold number as the focal point (e.g. "87 responses in 30 days"), small supporting caption text below it, Survyra logo top-left, #1E3A5F background with #F2A93B number, plenty of negative space, no clutter — this card needs to be readable in a 1-second scroll-past glance.
```

**Screenshot showcase (dashboard/survey/website)**
```
Design a square (1:1) layout with a single product screenshot placed inside a clean browser-chrome or phone-frame mockup, centered, drop shadow, headline text reserved above the frame, Survyra wordmark small in a corner, background solid #F7F5F0, no more than one accent color used.
```

**Offer/pricing card**
```
Design a square (1:1) pricing-card layout: Survyra logo top, bold headline "[Offer name — e.g. Growth Package] — ₹[X — e.g. 3,000]/month" (fill in per tier from [pricing-offers.md](pricing-offers.md)), a checklist area for 4-6 included items with small checkmark icons in #F2A93B, a CTA button-style bar at the bottom reading "DM 'DEMO'", background #1E3A5F with white/#F7F5F0 card surface for contrast.
```
