# Phase 6 (Days 22–25) — Turn Clients Into Proof

Extremely important: your first customers aren't just revenue — they become your marketing assets.

---

## Get Screenshots

Ask permission to show:

- [ ] Website
- [ ] Survey
- [ ] Dashboard
- [ ] QR code
- [ ] Feedback
- [ ] Results

## Get a Testimonial

- [ ] Ask: *"What did you like about the system?"*
- [ ] Push for something specific, not generic. Good: *"We finally have an easy way to collect feedback from our customers."* Bad: *"Great service."*

## Build the First Case Study

Template — copy this structure for each client:

```
## How [Client Name] Started Collecting Customer Feedback

Before: [no structured feedback system / whatever their actual "before" was]
After: [QR feedback system + survey + dashboard, specifics]
Result: [actual number — e.g. "87 responses in the first month"]
```

- [ ] Case study #1 drafted using **real data only** — no invented numbers
- [ ] Case study reviewed/approved by the client before publishing anywhere

### Phase 6 exit checklist
- [ ] Screenshots collected from at least 1 live client
- [ ] At least 1 specific (non-generic) testimonial captured
- [ ] At least 1 case study written with real, client-approved numbers
